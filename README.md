# Документация по функциям файловой системы

## Функция: fs_open_or_create

**Описание:**  
Открывает файл файловой системы по указанному пути. Если файл не существует, создаёт новый пустой файл.

**Параметры:**  
- `const char *fs_path` — путь к файлу файловой системы (строка).

**Возвращаемое значение:**  
- `FILE*` — указатель на открытый файл, или `NULL` при ошибке.

---

## Функция: fs_get_file_content

**Описание:**  
Возвращает содержимое файла внутри файловой системы по его имени. Для этого функция разбивает содержимое всей ФС по строкам, находит имя файла, а затем собирает все строки после имени до следующего имени файла.

**Параметры:**  
- `const char *fs_content` — строка с содержимым всей файловой системы.  
- `const char *filename` — имя файла, содержимое которого нужно получить.

**Возвращаемое значение:**  
- `char*` — динамически выделенная строка с содержимым файла (с символами перевода строки), или `NULL`, если файл не найден или произошла ошибка. Необходимо освободить память после использования.

---

## Функция: fs_delete_file

**Описание:**  
Удаляет файл из файловой системы по имени. Функция разбивает содержимое ФС по строкам, пропускает имя файла и все его содержимое до следующего имени файла, формируя новую строку с обновлённым содержимым.

**Параметры:**  
- `const char *fs_content` — строка с содержимым всей файловой системы.  
- `const char *filename` — имя файла, который нужно удалить.

**Возвращаемое значение:**  
- `char*` — динамически выделенная строка с обновлённым содержимым файловой системы после удаления файла, или `NULL` при ошибке. Необходимо освободить память после использования.
